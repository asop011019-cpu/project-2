### ANL-001에서 고칠 부분(최소 변경안)
1. 인증: "쿠키 세션·401 SESSION_REQUIRED" → 로그인 세션 가드(`createAuthGuard`)로 401·`CONSENT_UPDATE_REQUIRED` 403 그대로 적용. 분석 경로만 선택 동의 `ai_analysis` 없으면 403 `CONSENT_REQUIRED`(AUTH-001 확정).
2. 마이그레이션: "v4 제안과 함께" → 현재 v7 다음 **v8**에 `garments.image_sha256`(기존 행은 파일로 채움), `garment_analyses`, `garment_attributes` 추가. 삭제는 `deleteForUser`·하의 삭제 트랜잭션에 포함(30일 유예 뒤 삭제와 같은 경로).
3. 동기/비동기: 개발 단계는 동기(약 30초 제한)로 결정됨 → `POST …/analysis`는 202 대신 **200 + 최종 status**(completed/failed/unavailable) 반환, 202·queued는 확장 단계 대기열용으로 남김. 프론트는 status만 보면 되므로 전환 시에도 불변.
4. 어휘: ANL-001의 `color/silhouette/materialFeel` 3개 → VOC-001(`bottoms-vocab-0.1`)의 축 구조로 확장. 저장은 축별 값 + `rawText` 원문, 섬유 혼용률은 사진 추정 금지(사용자·상품 제공값만). 7-2 보류였던 세부 종류는 `construction`·`skirt_structure` 축으로 흡수.
5. 다른 계정 접근: 세션→계정 1:1이라 기존 소유 확인 그대로 적용, 다른 계정은 404.

### VOC-001 확인 (`bottoms-vocab-0.1.json`, 2026-10-26)
- JSON 파싱 정상. 축 10개·값 77개, 값 중복 0, 용어 24개 ID 중복 0, 용어·시험 사례 13개의 축 참조 오류 0. 겹치는 동의어는 의도된 슬랙스↔트라우저뿐.
- 제안(미확정) 용어 7개, 미결정 5개(영문 trousers, 코튼 팬츠/면바지, 큐롯의 치마 후보 여부, 강조어, 1차 용례 보강) → M1.4에서 큐레이터 확정 전에는 사실로 확정하지 않음.
- 최소 초기 속성 제안: `category`, `construction`/`skirt_structure`, `material_look`, `silhouette`, `length`, `color` + `rawText`. `waist_detail`·`hem_detail`·`fiber_composition`은 사진 추론 낮음/불가라 사용자·상품 정보로만.

## 3. 비용과 제한 (M1.3)
- 사용자 1회 흐름 예: 분석 1회(≈1~2원) + 코디 생성 텍스트 1회(후보 목록 포함, ≈5원 추정) + 착장 3장 + 재생성 1장(4×94원) ≈ **400원**.
- 월 상한 환산: 30만원 ≈ 약 750회 흐름(착장 약 3,000장), 200만원 ≈ 약 5,000회. 비공개 시험(예: 20명×10회=200회) ≈ 8만원.
- 제한 방법(코드로 강제): 앱 DB의 월 누적 예상 비용 카운터가 상한에 닿으면 호출 중단(503, 화면은 "준비 중"), 사용자별 하루 횟수(분석·착장 따로), 착장은 사용자가 눌렀을 때만 생성, 같은 상품 조합·모델 버전은 결과 재사용, 미리보기 0.5K 후 필요할 때 1K. 클라우드 예산 알림은 알림용이라 자동 차단으로 보지 않음.

## 4. 사용자 결정 필요 (이미 정해진 것 제외)
1. 분석 공급자: Gemini 3.1 Flash-Lite(추천) / OpenAI gpt-5.4-nano.
2. 착장 공급자: Gemini 3.1 Flash Image(추천) / Vertex AI Virtual Try-On.
3. 비용 상한: 비공개 시험 월 상한(추천 10만원) + 사용자별 하루 횟수(추천 분석 10회·착장 5장).
4. 전송 조건: 유료 등급만 사용, 국외 처리·보관을 `ai_analysis` 동의 v2에 공급자·국가·항목·기간으로 명시. Gemini 선택 시 **만 18세 이상만 가입**(가입 화면·약관에 반영) 필요 — 미성년 이용을 허용하려면 다른 공급자.
5. 상품 이미지 전송: 착장 생성에 판매처 상품 이미지를 공급자에게 보내도 되는지(무신사·유니클로 자료는 비공개 시험 한정). 공개 전 권리 확인 필수.
- 이미 결정됨(재질문 안 함): 사용자 사진 자체 학습 금지, 키는 서버 환경변수만, 개발 단계 동기 처리·확장 시 대기열, 동의는 가입 때, 구매 링크는 보내지도 방문하지도 않음.
