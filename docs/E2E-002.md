# E2E-002 Claude 기준 분석·코디 비용과 착장 생성 경로 (M1.2~1.3, 조사만)

- 기준: `feature/auth-002-kakao` a31ea45. 사용자 결정(2026-10-27): **Gemini 제외**. 사진 분석은 Claude(데이터 큐레이터), 착장은 우선 Claude 담당 후 Higgsfield 이전 희망.
- 코드·DB·외부 설정 변경, 실제 API 호출, 사용자 사진 전송 없음. 비용 상한·유료 호출·사진 외부 전송은 아직 승인 전.
- 가격은 2026-10-27 공식 문서 확인값, 환율 1달러=1,400원 가정. 토큰 수는 아래 가정에서 나온 **추정**.

## 1. 결론
| 기능 | 가능한 경로 | 판정 |
|---|---|---|
| 사진 분석 | ① 앱 서버 → Anthropic API(Claude 비전) 자동 호출 ② 큐레이터 Claude 채팅 수동 작업 | ① 앱 기능에 맞음(종량 과금). ② 비공개 시험 사진의 기준 정답 만들기·검수에만 맞음(사람이 깨워야 함) |
| 코디 추론 | Anthropic API로 후보 상품 ID 목록 중 조합 선택(RAG) | 가능 |
| 착장 이미지(래스터) | **Claude 불가.** 공식 문서: Claude는 이미지 이해 전용이며 이미지를 생성·편집하지 못함. 큐레이터 환경에도 생성 도구 없음(큐레이터 회신) | Claude는 생성 지시문 작성·결과 일치 검수(M5.2)만 담당. HTML/SVG/프롬프트는 착장 생성으로 보지 않음 |
| 착장 생성 대안 | Higgsfield API | 가상 착용 모델 존재·가격 **미확인**(아래 4장) → 비용 계산 안 함 |

## 2. Claude 구독과 API는 별개
- Claude Pro: 월 $20(연간 결제 시 월 $17). **앱용 API 사용량은 포함되지 않음**, 사람이 Claude 앱에서 쓰는 용도. 앱 서버 자동 호출은 Console 계정의 API 종량 과금.
- API 데이터: 입력·출력은 30일 안에 삭제(기본), 무보관(ZDR)은 별도 계약. 공식 비전 문서: 업로드 이미지는 모델 학습에 쓰지 않음, 요청 후 보관하지 않음(Files API로 올린 경우 제외).
- 큐레이터 Pro 구독비는 이미 쓰는 고정비라 아래 API 비용과 합산하지 않음.

## 3. API 비용 추정 (사진 분석 + 코디 추론)
### 단가(1M 토큰, 표준) — 공식
| 모델 | 입력 | 출력 | 캐시 읽기 |
|---|---|---|---|
| Claude Haiku 5.5 (`claude-haiku-5-5`, 10만 토큰 이하 요청) | $0.10 | $0.50 | $0.01 |
| Claude Sonnet 5.5 (`claude-sonnet-5-5`) | $2 | $10 | $0.10 |
| Claude Opus 5.5 (`claude-opus-5-5`) | $4 | $20 | $0.20 |
- 지역 고정(`inference_geo: "us"`)은 1.1배, Batch API는 50% 할인(비동기라 즉시 응답 화면에는 안 맞음).

### 토큰 가정
- 사진: 이미지 토큰 = ⌈가로/28⌉×⌈세로/28⌉(공식). 서버에서 긴 변 1024px로 줄이면 768×1024 → **1,036 토큰**.
  - 정정: 큐레이터 안의 "긴 변 1568px·약 1.3k 토큰"은 구형 모델 기준. Claude 4.7 이후 모델은 긴 변 2,576px까지 줄이지 않아 1568×1176이면 약 2,352 토큰이 됨 → 서버에서 1024px로 줄여 보냄.
- 분석 1회: 사진 1,036 + 지시문·VOC 어휘 약 2,500 = 입력 약 3,500 / 출력 JSON 약 500.
- 코디 1회(3개 조합): 하의 속성·조건·취향 약 1,000 + 후보 상품 60개×80 = 4,800 + 지시문 700 = 입력 약 6,500 / 출력 약 1,200.
- 확장 사고(thinking) 미사용 가정. 사용하면 출력 토큰 증가.

- 캐시: 어휘 지시문(약 2,500 토큰)을 캐시하면 Sonnet 분석 1회당 약 $0.0045 절감. 단 5분 안에 다음 호출이 있어야 효과, 소량 시험에선 작음.
- 호스팅: 서버·저장소 비용은 미정이라 따로 계산(이 표에 없음).
- 착장 이미지 비용은 4장대로 미확인이라 **합산하지 않음**.

## 4. Higgsfield (후속 후보) — 공식 문서 확인 범위
- 연동: REST API(`api.higgsfield.ai`)·Python/TypeScript SDK, 요청은 비동기(request_id → 상태 조회 또는 웹훅).
- 과금: 선불 잔액에서 성공한 생성만 차감, 실패·NSFW 판정은 미과금. 잔액은 충전 후 1년 만료. **모델별 가격은 문서에 없음** — 로그인한 계정의 예상 비용 조회(estimate)가 기준.
- 보관: 요청 파일 7일 보관 후 삭제, `Hf-Expires-After`(최소 1시간)로 단축, 요청 삭제 API로 즉시 삭제 가능.
- 학습: **출력물 학습 제외 설정이 기본 꺼짐** → 사용 시 반드시 켜야 함. 입력(사진) 학습 여부는 문서에 없음.
- **가상 착용 모델 존재 미확인**: 공개 문서 목록에 착용·의류 합성 모델이 없고, 모델 목록은 로그인한 콘솔에서만 보임.
- 확인 필요(사용자가 콘솔에서, 결제 없이): 착용/여러 참조 이미지 모델 유무, 해당 모델 estimate 금액, 입력 학습 여부, 상업적 이용 조건.

## 5. 기존 계약 영향과 다음 단위
- ANL-001 수정안(E2E-001 1장)은 공급자만 Anthropic API로 바뀌고 그대로 유효: v8 마이그레이션, `POST …/analysis` 동기 200 + 최종 status(약 30초 제한), `ai_analysis` 미동의 403, 사진 해시 재사용, 어휘는 VOC 축 + rawText.
- `ai_analysis` 동의 v2 필요: 공급자(Anthropic)·처리 국가(미국 등)·보내는 항목(사진, 사용자가 입력한 브랜드·제품명 글자)·보관(30일 내 삭제)·학습 미사용 명시. 구매 링크는 보내지 않음.
- 연령: Anthropic 소비자 약관은 만 18세 이상이나, API로 미성년에게 제공할 때의 조건은 이번에 공식 확인 안 함 → 결정 전 확인.
- 다음 단위:
  - **M2.0**(결정 없이 가능): v8 마이그레이션 + 분석 API + 공급자 인터페이스와 모의 구현, 다른 계정 404·재사용·사진 교체 재확인 테스트. 모의 결과를 실연동으로 보고하지 않음.
  - **M2.1**(승인 후): Anthropic 어댑터 — 서버 키(사용자 직접), 비용 상한 카운터, 동의 v2.
  - **M3.1**: 계절·상황·격식·추가 예산 조건 저장·복원 계약.
  - **M5**: Higgsfield 콘솔 확인 전 보류.

## 6. 사용자 결정 필요
1. 분석·코디 모델: Sonnet 5.5(정확도 우선) / Haiku 5.5(비용 우선) — 비공개 시험 사진으로 둘 다 비교 후 확정 제안.

4. Higgsfield 콘솔에서 착용 모델·예상 금액 확인(사용자 계정 필요).
