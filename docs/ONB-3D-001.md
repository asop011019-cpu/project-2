# ONB-3D-001 스타일 선택 3D 카드 탐색 (M6.2)

- 기준: `feature/mot-001-interactions@62243fb`(MOT-001과 그 뒤 사용자 직접 수정 포함, gar-002@9d6a569 기반) → 작업 브랜치 `feature/onb-3d-style-scroll`. COND 브랜치 파일은 건드리지 않음. 검증된 통합 브랜치는 없음(로컬 미리보기용 병합 `preview/cond-mot`은 푸시하지 않음).
- 새 의존성·WebGL·Three.js 없음. 기존 CSS transform과 브라우저 기본 스크롤·스냅만 사용.

## 사용자 결정 (2026-10-28, 구현 중 확인)

- 장르(포멀·유러피안 등)는 **위아래로 밀어** 바꿈. 하위 스타일은 각 장르 안에서 **좌우로 넘기는 3D 카드**.
- **"별로" 버튼 제거**. 응답 버튼은 맨 아래 **"건너뛰기" 하나**. 좋아요는 기존대로 사진 두 번 탭(또는 사진 하트).
- 카드를 밀어서 응답하던 방식(오른쪽=좋아요, 왼쪽=별로, 위=건너뛰기)은 좌우 밀기가 스타일 넘기기로 바뀌어 삭제(`lib/swipe.ts`와 그 테스트 삭제).

## 동작

| 조작 | 결과 | 저장 |
| --- | --- | --- |
| 카드 줄을 좌우로 밀기(터치·트랙패드), 줄에 초점 두고 화살표 키, 옆 카드 누르기 | 가운데 멈춘 카드가 현재 스타일. 이름·설명·추가 사진이 그 카드와 일치 | 위치만(`PUT /session/position`). 좋아요·별로·건너뛰기 저장 없음 |
| 장르 영역을 위아래로 밀기(또는 초점 후 화살표 키) | 한 번에 한 장르씩 넘어감. 그 장르에서 마지막으로 본 카드(없으면 첫 응답 가능 카드) 선택 | 위치만. 사진 없는 스타일은 읽기 전용 상세, 요청 0 |
| 장르 목록·스타일 직접 선택, "← 이전 / 다음 →" | 기존 그대로. 카드 줄이 해당 장르·카드로 따라 움직임 | 위치만 |
| 가운데 카드 사진 두 번 탭 / 하트 / 확대 | 기존 그대로(좋아요 / 사진 선호 / 크게 보기). 밀다가 손을 뗀 경우(10px 이상 움직임)는 탭으로 치지 않아 하트·좋아요 오작동 없음 | 기존 계약 |
| 맨 아래 "건너뛰기" | `skipped` 저장 후 다음 스타일로(카드도 따라감) | 기존 계약 |

- 깊이감: 가운데 카드 정면·원래 크기, 옆 카드는 스크롤 위치에 따라 최대 26° 기울기·86% 크기·투명도 0.6, 가운데 쪽 모서리를 축으로 줄어 양옆이 보임. 그림자는 기존 카드 그림자 1개, 흐림·반사 없음.
- 앱이 현재 스타일을 옮길 때(목록 선택, 이전/다음, 응답 후 다음)는 그 스크롤을 사용자 선택으로 보지 않음. 저장이 실패하거나 다른 저장 중이라 무시된 이동은 가운데 카드를 현재 스타일로 되돌림.
- 사진 로드: 현재 카드와 같은 줄의 양옆, 위·아래 장르의 첫 카드만 미리 불러옴. 나머지 카드는 이름만. 추가 사진은 `loading="lazy"`.
- `prefers-reduced-motion`: 기울기·크기 변화 없이 평면 카드 스냅, 같은 조작 가능.
- 접근성: 장르 영역·카드 줄 모두 초점 가능, 장르 행 `aria-current`, 카드 `aria-label="n / N: 이름(, 사진 준비 중)"`, 현재 카드 `aria-current`.
- 세로 스크롤: 장르 영역 밖에서는 페이지가 그대로 스크롤. 장르 영역 안에서 위아래로 밀면 장르가 넘어가고, 맨 위·맨 아래 장르에서는 페이지로 이어짐(브라우저 기본 스크롤 연결).
