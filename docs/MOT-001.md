## 1. MORSE식 상태 전환

| 위치 | 파일 | 동작 |
| --- | --- | --- |
| 저장 버튼("저장하기", 시트의 "옷 정보 저장") | `components/motion/StatusButton.tsx`, `GarmentScreen.tsx` | 한 버튼 안에서 대기 → 저장 중(하단 진행선) → 저장했어요(체크) / 다시 저장. 문구는 짧은 흐림으로 교체. 모든 문구가 같은 칸에 겹쳐 있어 폭이 바뀌지 않음. 성공·실패는 서버 응답 뒤에만, 1.6초 뒤 원래대로 |
| 연속 클릭 | 같은 파일 | 진행 중엔 비활성. 같은 순간 두 번 누르는 경우(비활성이 그려지기 전)도 잠금으로 1번만 전송 |
| 시트 열기·닫기 | `GarmentSheet.tsx`, `styles.css` | 스프링 곡선으로 올라오고(데스크톱은 오른쪽에서), 닫힐 때 같은 길로 내려간 뒤 사라짐. 배경도 함께 페이드 |

## 2. BUILD THE FLOOR식 인트로

- 파일: `IntroScreen.tsx`, `styles.css`.
- "입고 싶은" · "가능성" 두 줄이 각자의 마스크 안에서 아래에서 올라와 반동 없이 자리 잡음(0.9초, 둘째 줄 0.14초 뒤). 부제는 오른쪽 정렬선에서 열림.
- 문구·색·사진·글꼴·배치는 그대로. 최종 위치를 원래 값과 비교: 첫 줄 위 214px, 둘째 줄 262px로 동일(375px).
- "내 취향 찾기" 버튼은 첫 프레임부터 보이고 바로 누를 수 있음(모션 대기 없음).

## 3. twoclipping식 코디 쇼케이스

- 파일: `components/showcase/OutfitShowcase.tsx`, `lib/showcase.ts`, 개발용 경로 `routes/dev.showcase.tsx`(`/dev/showcase`, 운영 빌드는 404, noindex).
- 가로 스와이프(브라우저 기본 스크롤 + 스냅이라 세로 스크롤과 충돌 없음), 이전·다음 버튼, 좌우 화살표 키로 전환. 가운데 카드가 앞으로 나오고 나머지는 물러남. 현재 카드 제목은 마스크에서 다시 등장. "1 / 3" 표시는 화면 낭독기에 알림.
- "구성·참고가 보기" → 시트에서 품목·참고가·판매처 링크. 기준 옷은 "구매 안 함"이고 합계에서 제외. 참고가가 빠진 품목이 있으면 "이상 (일부 참고가 없음)". http(s) 외 링크는 표시하지 않음, 새 창은 `noopener noreferrer`. 사진은 `object-contain`(잘림·왜곡 없음).
- 시험 데이터 `DEV_SAMPLE_OUTFITS`: "시험 코디 A~C", "시험 품목", 이미지·링크 없음, 화면 상단에 "실제 상품·추천 결과가 아님" 표시. **M4 결과 화면 통합은 미완료**(실상품·서버 검증 데이터 없음).

## 사용자 요청 반영 (같은 브랜치)

- 기준 옷 화면 왼쪽 위에 "← 취향 탐색으로"(조건 화면 뒤로가기와 같은 위치), `/?explore=1`로 이동.
- 범주 선택 화면의 뒤로가기 제거(앞 화면이 인트로뿐). 기존 테스트를 새 동작으로 바꿈.
- 404 "처음 화면으로"와 오류 화면 "홈으로 가기"는 인트로 없이 남성복·여성복 선택(`/?explore=1`)으로 이동.
- 취향 확인 → 사진 등록: 버튼("취향 저장하고 기준 하의 등록으로") 대신 화면을 오른쪽에서 왼쪽으로 밀면 책장처럼 넘어감(`components/motion/PageTurn.tsx`). 왼쪽 가장자리를 축으로 손가락을 따라 기울고, 폭의 35% 이상 또는 빠르게 밀면 넘어가 저장(`POST /session/complete`) 후 `/garment` 이동. 짧게 밀면 제자리, 세로로 밀면 스크롤. 저장 실패 시 페이지가 돌아와 오류 표시. 아래에 "← 밀어서 넘기기: 취향 저장하고 사진 등록으로" 안내(키보드·화면 낭독기용으로 눌러도 같은 동작).
- 단계 사이 커튼 전환 제거(사용자: "별로"). 인트로→범주→탐색→요약이 바로 바뀜. `useCurtain.ts` 삭제.
