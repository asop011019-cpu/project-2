- 브랜치: `integration/onb-003-like-flow` (기준 `integration/int-001-b-local-session` 5f86ab1)
- 프론트: Lovable `bdf7c72a57b272ddce21451a436702ed94269aa1` (29921715 대비 6개 파일 반영, `frontend/SOURCE.md`)
- 사용자 요청: 카드 두 번 탭 → 작은 하트 애니메이션과 함께 DB에 좋아요 저장, 좋아요 숫자 카운터 대신 위쪽 하트에 색으로 상태 표시, 단계별 뒤로 가기.

## 동작
- 카드 사진 영역 더블탭/더블클릭 → `PUT /api/onboarding/session/styles/:styleId/response` `{"response":"liked"}` (nextStyleId 없음, 현재 카드 유지). 56px 하트가 0→1.1→1로 나타났다 0.6초 안에 사라짐. 한 번 탭은 아무 동작 없음. 이미 liked면 요청 없음. 실패 시 상태 복원+알림, 401 자동 초기화 없음.
- 상단: 숫자 카운터 제거, 하트+"좋아요". 현재 스타일이 liked면 하트가 #CEC7D6로 채워짐. 옷걸이 레일 유지.
- 뒤로 가기(44×44): 취향 확인 → 고르기 → 범주 → 인트로, /privacy는 이전 화면. 저장된 범주·응답은 지우지 않음. API 계약 변경 없음.

## 로컬 테스트 콘텐츠 (격리 DB 전용, 저장소에 없음)
- `backend/data/int-001-b/assets/test/*.png` 12장: "테스트 · 임시 이미지 · 실제 사진 아님" 표기 자리 표시 이미지(600×800).
- `backend/data/int-001-b/test-content.json`을 `npm --prefix backend run catalog:import`로 격리 DB에만 등록: men_classic, men_modern_formal, men_business_casual 각 4장(published/allowed, creator "로컬 테스트용 자리 표시"). `backend/.env`에 `ASSET_ROOT=./data/int-001-b/assets` 추가.
- 전부 gitignore 대상(`backend/data/`, `.env`). 운영 DB·배포 자산에 포함 금지. 정리하려면 `backend/data/int-001-b/` 삭제.
- 기존 세션은 콘텐츠 등록 전 목록에 고정되므로, 테스트 브라우저 세션을 DELETE 후 새로 시작해 확인함.
