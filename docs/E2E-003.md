## 3. 수정한 결함
- 로그인 안내 "내 취향과 **하의 기록**" → "내 취향과 **옷장**". 옷장은 이제 모든 종류를 저장함.
- 탈퇴 안내 "취향 기록과 **하의 사진·정보**" → "취향 기록과 **내 옷장의 옷 사진·정보**". 유예 기간 동안 옷장 전체가 보관됨(삭제는 기간 만료 시 일괄).
- 회귀 테스트: `onboarding-screen.test.tsx` "지운 이전·다음 줄, 응답·장르 카운터, 요약 넘김이 되살아나지 않는다".
- **요약의 "취향 저장" 버튼**(사용자 결정, 2026-10-29): `canComplete`는 모든 스타일에 응답해야 참인데 화면의 스타일별 응답은 좋아요뿐이라, 일부만 좋아요하면 버튼이 꺼져 있었음. 이제 좋아요가 1개 이상이면 버튼이 켜지고, "좋아요한 스타일만 취향으로 반영" 안내 후 사진 등록으로 감. 좋아요는 누를 때 이미 저장되므로 완료·응답 요청을 보내지 않고, 남은 스타일은 미응답 그대로(건너뜀으로 꾸미지 않음). 모두 응답한 경우는 기존대로 완료 요청. API 변화 없음. 테스트 "일부만 좋아요해도 취향 저장으로 넘어가되, 완료·응답 요청은 보내지 않는다" 추가.
- 처리방침 초안(사용자 결정, 2026-10-29): "기준 하의 사진"·"기준 하의 등록"·"하의 사진" → "내 옷장 사진"·"내 옷장 등록"·"내 옷장 사진". 빈칸 항목은 그대로.

- 요약의 **"별로"·"건너뜀"** 칸 숨김(사용자 결정, 2026-10-29): 예전 스타일별 좋아요/별로/건너뛰기 버튼이 있던 때의 개수라 지금 화면으로는 새로 고를 수 없음. "남음"만 남김. 서버의 옛 응답 기록·API는 그대로.

## 5. 사용자 실기기 확인 (미실행)
1. 휴대폰으로 같은 Wi-Fi에서 앱을 열고 로그인 → 남성복 → 카드를 좌우로 밀고 위아래로 장르를 넘겨, 넘김이 서로 섞이지 않는지 확인.
2. 대표 사진을 두 번 탭해 하트가 켜지는지, 한 번 탭이나 밀기로는 켜지지 않는지 확인.
3. [건너뛰기] → 사진 등록에서 카메라로 상의·하의를 1벌씩 저장하고 "내 옷장 2"가 되는지 확인.
4. 조건에서 0원을 고르면 안내가 한 번 뜨고, 저장 후 "옷장 옷 2벌로만" 문구가 보이는지 확인.
5. 휴대폰 설정에서 "동작 줄이기"를 켜고 장르·카드 넘김이 순간 이동으로 바뀌는지 확인.
