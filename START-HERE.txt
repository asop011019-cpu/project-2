Windows 실행 방법

1. Node.js 24 LTS (24.19.0 이상)를 설치하세요.
2. ZIP을 모두 압축 해제하세요. ZIP 안에서 직접 실행하지 마세요.
3. package.json과 START-HERE.txt가 보이는 폴더의 탐색기 주소창에 cmd를 입력하고 Enter를 누르세요.
4. 다음 명령을 한 줄씩 실행하세요.

npm ci
npm start

5. Chrome에서 http://localhost:5173 을 여세요.
6. 사용하는 동안 터미널을 열어 두세요. 종료는 Ctrl+C입니다.

npm ci는 첫 설치 때 필요합니다. 이후에는 npm start로 실행합니다.
이 주소는 내 PC에서만 사용하는 로컬 주소이며 공개 도메인이 아닙니다.
실제 사진이 아직 등록되지 않아 사진 영역은 준비 중 상태입니다.
